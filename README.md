# Stock Portfolio Tracker

## CodeAlpha Python Programming Internship

### Project Description
Stock Portfolio Tracker is a Python-based application that helps users calculate the total value of their stock investments using predefined stock prices.

### Features
- Displays available stocks and their prices.
- Accepts multiple stock symbols and quantities.
- Validates stock names and user inputs.
- Calculates the investment value for each stock.
- Displays the total portfolio value.
- Saves the portfolio summary to a text file.

### Technologies Used
- Python 3
- Dictionaries and lists
- Loops and conditional statements
- Exception handling
- File handling

### How to Run
1. Download the Python file from this repository.
2. Open it in VS Code or another Python editor.
3. Run the command:

   `python stock_portfolio_tracker.py`

4. Enter the number of stocks, stock symbols and quantities.
5. View the calculated portfolio value.
6. Enter `yes` to save the portfolio summary to `portfolio.txt`.

### Example
Stock: AAPL  
Quantity: 2  
Investment: $360

Stock: TSLA  
Quantity: 3  
Investment: $750

**Total Portfolio Value: $1110**

### Note
This project uses predefined stock prices for educational purposes. It does not retrieve live stock market prices.
